# ROADMAP — доработка симулятора до ТЗ

Репозиторий — ядро симулятора (ADR-006); основа — код NB-IOT-4 v4.0.0 (ADR-004). Модели учатся в Python (ADR-007). Большая часть функций ТЗ реализована и проверена короткими
тестами; открыты масштаб, данные, научные сравнения и отчёт. Этапы ниже — **черновик**: детальный план
каждого этапа составляется перед его началом (`superpowers:brainstorming` → `superpowers:writing-plans`,
план в `docs/superpowers/plans/`). Этап закрывается, когда: код есть, тесты зелёные, `verifier` дал
«принято», PROGRESS обновлён.

Обозначения: **КТ** — контрольная точка ТЗ §54; **Проверка** — чек-лист ТЗ §31–44. Полная карта
готовности v4 по §50 — `docs/section-50-readiness.md`.
